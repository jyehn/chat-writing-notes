Three endings, one invitation: a version log for branching chat dialogue

By Jam Hsiao

A branching conversation is easier to write when you can explain what changes at each fork. Otherwise, three endings may become three unrelated scenes that happen to share the same opening message. This notebook exercise starts with a fictional invitation, gives the recipient three reasonable responses, and tracks the consequences in a small version log. You can use the method for an interactive story prototype, a writing workshop, or a set of alternative scenes without building a functioning app.

Define the shared situation

Write a situation that stays true in every version: “Nico invites Bea to help paint a cardboard moon for a neighbourhood play on Friday afternoon.” The moon is a prop, the people are invented, and the exchange is a writing example. None of the versions should quietly change the day, the purpose of the task, or the relationship between the characters. Those details form the common starting point.

Now choose one decision for Bea. She can accept, decline, or suggest another way to help. These options have different consequences, but each can be expressed naturally. Avoid offering one sensible response and two absurd ones just to make the story appear interactive. The interesting work is in showing how Nico responds to an ordinary choice without making the character inconsistent across versions.

Write the common opening once

Use two messages as the shared opening:

Nico: Can you help me paint the cardboard moon on Friday afternoon?

Nico: We need it ready for the neighbourhood play on Saturday.

Keep these messages in a separate “opening” section of your document. Copy them into each visual version only when you prepare the images. During drafting, storing the opening once reduces the chance that a small change reaches only one branch. If you decide the task should happen on Thursday instead, change the shared note and check all three endings before exporting anything.

Branch A: an agreement that creates a practical next step

Bea: Yes. I can arrive after three.

Nico: Perfect. I will cover the table before you get here.

Bea: Do you need me to bring a brush?

Nico: A wide one, if you have it. We can use mine for the edges.

This ending is cooperative and concrete. The next step is preparation for a shared task. Record its consequence in the version log: “Bea attends after three; Nico prepares the workspace; Bea brings a wide brush if available.” The conditional phrase matters. Do not later write that Bea definitely owns the brush unless another message establishes it.

Branch B: a refusal that still respects the relationship

Bea: I cannot make Friday. I already promised to help my cousin move.

Nico: Thanks for letting me know. I will ask someone else.

Bea: Send me a picture when the moon is finished.

Nico: I will. You can judge the craters from a safe distance.

Here the practical plan changes, but the characters remain friendly. The light final line does not punish Bea for declining. Record the consequence: “Bea does not attend; Nico needs another helper; they remain interested in each other's work.” This version does not need to converge on the same painting session as Branch A. A meaningful choice is allowed to produce a different outcome.

Branch C: an alternative contribution

Bea: I cannot stay to paint, but I could cut out the stars on Thursday.

Nico: That would help. Could you make three large ones?

Bea: Yes. Leave the cardboard by the rehearsal-room door.

Nico: I will put it there before lunch on Thursday.

This branch changes the type of help instead of merely changing the time. Its consequence is another commitment: Nico must leave the cardboard where Bea can collect it. Add that obligation to the log. If a later scene depends on finished stars, the writer should be able to trace that event back to these messages rather than assuming it happened between scenes.

Use a version log to prevent accidental contradictions

Make one row for each branch with four fields: version name, Bea's decision, Nico's next action, and unresolved detail. For A, the unresolved detail is whether Bea has a wide brush. For B, it is who replaces Bea. For C, it is whether the cardboard has been left at the door. These are useful continuation prompts. They are not defects that must all be resolved in the same short exchange.

Read each branch after the common opening and then read the branches without their labels. Can you identify the different outcome from the dialogue alone? If two branches produce exactly the same action, consider whether their distinction is emotional rather than practical and record that deliberately. If a branch depends on an event absent from the opening and its own messages, add the missing line or remove the dependency.
